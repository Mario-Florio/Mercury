# Mercury
A static site framework for reducing the friction associated with publishing intellectual content.

## Packages

| Folder | Package | Responsibility | License |
| --- | --- | --- | --- |
| `packages/core` | `@mercurypress/core` | Mercury's independent domain and publishing pipeline. | GPL-3.0-or-later |
| `packages/astro` | `@mercurypress/astro` | Mercury's Astro adapter integration. | MIT |
| `packages/create` | `@mercurypress/create` | Script for creating a Mercury starter site. | MIT |

## Development

**Requirements:** Node >=22.18.0 (direct TypeScript execution)

Run tests:

```
npm run test
```

Check types:

```
npm run check
```

Format:

```
npm run format
```

> **Disclaimer:** All commands should be executed from respository root.
